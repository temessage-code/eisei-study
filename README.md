# 第一種衛生管理者 学習ノート

iPhoneのSafariで使える学習Webアプリ。ビルド不要のHTML・CSS・JavaScript構成です。

## 機能

- 通常学習、ランダム、分野別、間違えた問題、苦手問題、模擬試験
- 70問・5分野、回答後の解説・覚え方・参照先
- 模擬試験44問・180分・分野別の配点と合格基準による採点
- 学習記録・途中の回答を端末内に保存

## GitHub Pagesで公開する

1. リポジトリの Settings → Pages を開く。
2. Build and deployment の Source で Deploy from a branch を選ぶ。
3. Branch を main、フォルダを /docs にして Save。
4. 公開処理が完了したら、Pages画面に表示されるURLを開く。

想定URL: https://temessage-code.github.io/eisei-study/
このURLは設定と公開処理が完了して初めて利用できます。

非公開リポジトリでは、契約によりPagesを使えない場合があります。Pages画面で利用条件を確認してください。リポジトリの公開範囲の変更はソースコードも公開する操作です。

iPhoneではSafariで公開URLを開き、共有 → ホーム画面に追加。問題と解説は通信が必要です。端末・ブラウザ間の学習記録の同期はありません。ブラウザのデータ削除で記録が消える場合があります。

## ローカルで確認する

Node.jsで `node tests/check.cjs` を実行すると、出題・復習・再開・模試構成・採点・時間切れを検証します。
`python3 -m http.server 8000 --directory docs` で起動し、http://localhost:8000 を開くと試用できます。

## 教材について

以前作成した頻出テーマ版を移植しています。過去問題そのものの転載ではなく、テーマに基づくオリジナル練習問題です。各問題に参照先、テーマ別に頻度分析の根拠を収録しています。今回の移植では過去問題の頻度分析と法令内容を再監査していません。公開前に最新の公式教材・法令との照合を推奨します。本アプリは公式試験提供元とは無関係で、合格を保証するものではありません。
